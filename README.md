## Why MongoAdmin

- **Native performance**: built with Rust and Tauri, under 50 MB. No Electron.
- **Generous free tier**: the core features are free forever for personal use.
- **Privacy first**: your data and credentials stay on your machine.
- **Built for real workloads**: 45+ features, 3k+ automated tests.

## Features

| Feature | Plan |
|---|:---:|
| Aggregation pipeline builder with stage preview and real-time results | Free |
| SSH tunneling, Kubernetes discovery (kubeconfig scan, MongoDB pods) | Pro |
| Visual drag-and-drop query builder | Pro |
| SQL to MongoDB translation (find / aggregate) | Pro |
| Performance monitoring: slow queries, index usage, live operations | Pro |
| Fleet management: replica sets, sharding, multi-connection dashboard | Enterprise |

See the full list on [mongoadmin.dev/features](https://mongoadmin.dev/features) and plans on [mongoadmin.dev/pricing](https://mongoadmin.dev/pricing).
